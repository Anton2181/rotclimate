# Fixed-grid matched meteorological packets

NASA POWER daily LST2020–2024, all thirty previously declared tile-centre samples.
The packets add PRECTOTCORR to the previous eight-variable weather request.
Original URLs, metadata, units, provider geometry and byte/semantic hashes are
in sources.json. The new capture retains source responses without editing them.

Protocol: calibration/matched_regional_weather_20261114/plan.json.
Input review: output/matched_regional_weather_20261114/review.json.
These are modern gridded weather inputs, not station or ancient measurements.
